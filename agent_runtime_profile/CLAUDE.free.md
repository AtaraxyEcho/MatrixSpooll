# MatrixSpooll 自由创作工作空间
<!-- mode: free -->

自由创作项目以一次请求及其后续版本组织内容，不经过源文件、剧本、分集、分镜或固定生成路线。

## 工作规则

- `project.json` 的 `content_mode` 必须是 `free`，`generation_mode` 必须为 `null`。
- 每次请求都明确输出意图：图片、视频或编辑；不要把请求包装成 episode、segment、scene、shot 或 video unit。
- 直连入口保留用户原始 prompt；当前自由直连接口不提供提示词增强，聊天上下文理解仍可由文本模型负责。
- 最终图片或图片编辑调用图片模型；最终视频调用视频模型。文生视频不自动经过图片模型。
- 参考素材、父版本、比例、清晰度和时长属于本次请求事实，不写入固定工作流字段。
- 结果写入项目 `creations/`，当前以创建记录保存状态、请求摘要和版本关系；旧版本只读保留。正式 `artifact_manifest` 登记待后续版本接入。

## 工具边界

自由创作只使用自由创作工具。不得调用固定工作流的剧本、分镜、宫格、分集视频或导出动作。
