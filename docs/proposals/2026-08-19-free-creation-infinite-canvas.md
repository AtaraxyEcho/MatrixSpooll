# 自由创作无限画布工作区方案

## 状态

已实施。本文记录自由创作工作区的交互边界；直连请求、结构化引用、画布视图状态和作品导出的领域口径以 [ADR-0064](../adr/0064-free-creation-project-mode-and-model-orchestration.md) 为准。固定工作流项目的任务和产物行为不变。

## 背景

项目已经支持 `content_mode=free`。自由项目使用 `generation_mode=null`，不进入源文件、脚本、分集、分镜或参考生视频工作流；现有领域决策见 [ADR-0064](../adr/0064-free-creation-project-mode-and-model-orchestration.md)。

改造前的自由创作页面复用标准工作区的组合方式：侧边栏、项目概览式表单和右侧助手面板同时存在。结果是源文件、角色集、场景库和道具库在自由项目中显示但没有对应的工作流，首页提交后也缺少从输入到生成结果的连续过渡。

本方案将自由创作项目详情页定义为一个项目内的无限画布工作区。它不是新的顶层应用，也不是新的 `generation_mode`，仍然通过 `/app/projects/:projectName` 访问。

## 目标

- 自由创作项目进入详情页后直接进入无限画布。
- 画布承载提示词、参考素材、生成结果和编辑分支之间的关系。
- 使用底部对话式生成框作为唯一主要创作入口。
- 原有智能体会话作为可选辅助能力，不与生成输入框竞争。
- 首页提交后平滑过渡到同一项目的画布并继续显示任务状态。
- 剧集、说书和广告项目继续使用现有标准工作区，行为和路由不变。
- 代码边界保持高内聚、低耦合，避免把自由模式判断散落到公共布局中。

## 非目标

- 不把自由创作提升为跨项目的独立创作空间。
- 不修改 `content_mode` / `generation_mode` 的含义。
- 不为自由项目生成 `scripts/episode_*.json`、分集账本或固定工作流状态。
- 不改造标准项目的 `AssetSidebar`、`OverviewCanvas` 或 `TimelineCanvas` 为自由模式专用组件。
- 不把所有媒体、文本和按钮绘制成不可访问的纯像素 Canvas。

## 工作区分流

在项目工作区入口完成一次模式选择：

```text
ProjectWorkspaceRouter
├── WorkflowWorkspace
│   ├── drama / narration / ad
│   ├── AssetSidebar
│   ├── OverviewCanvas / TimelineCanvas
│   └── AgentCopilot
└── FreeCreationWorkspace
    ├── InfiniteCanvas
    ├── FreeCreationComposer
    ├── FreeCreationSessions
    └── OptionalFreeAssistant
```

标准模式继续使用现有布局。自由模式不加载标准项目侧边栏和剧集区域，也不通过在公共组件中堆叠 `if (isFree)` 实现差异。

两种工作区只共享稳定的基础设施：认证、项目身份、顶部栏基础结构、Toast、任务状态、媒体预览、API 客户端和设计令牌。

自由工作区独立拥有画布节点、画布变换、选中状态、创作会话和输入框状态。它可以读取项目名称和自由产物，但不修改标准项目的脚本、分集、角色、场景或道具状态。

## 无限画布

自由项目不显示以下项目级入口：

- 源文件
- 角色集
- 场景库
- 道具库
- 剧集列表
- 标准项目概览

全局资产仍可通过底部输入框的“上传参考 / 引用素材”打开，不通过自由项目侧栏复制一套标准资产导航。

画布节点类型建议包括：

- 提示词节点
- 参考图片或参考视频节点
- 图片生成节点
- 视频生成节点
- 图片编辑节点
- 排队中、生成中、失败节点
- 继续编辑或继续生成节点

节点连线表达派生关系，例如：

```text
提示词 → 图片结果 → 图片编辑
              └──→ 图片转视频
```

节点支持拖动、选择、多选、可逆隐藏、继续编辑、查看版本、引用和下载。删除正式媒体不是画布布局操作；需要删除领域能力时必须同时处理版本、产物声明和被引用关系。画布提供缩放、平移和重置视图，不使用高密度发光或持续动画制造视觉噪声；撤销/重做、小地图和大规模节点虚拟化作为节点量增长后的增强项。

鼠标映射遵循常见画布直觉：默认光标保持普通箭头；左键点卡片只选择，按住卡片标题才移动节点；左键从空白处拖动形成框选；鼠标中键或 `Space + 左键` 平移画布；右键点卡片打开编辑、引用和隐藏等上下文操作。失败或未完成节点不暴露需要正式媒体的编辑/引用动作。

### 渲染技术边界

产品体验采用无限画布，但实现建议使用混合渲染：

- Canvas 或 SVG 层负责背景网格、连线、选择框、缩放和平移。
- React/HTML 层负责提示词、图片、视频、按钮、输入框和弹窗。
- 媒体节点保留 DOM 能力，以支持原生视频控制、键盘操作、无障碍和移动端布局。

纯原生 Canvas 会使文本编辑、焦点管理、视频播放、键盘交互和可访问性成本显著增加，不作为默认实现方向。

## 底部创作框

底部创作框是自由工作区的主要入口。它可以呈现为聊天框，但提交目标是自由生成任务，而不是标准 Agent 会话。

基础组成：

- 多行提示词输入
- 上传或拖入参考素材
- 图片 / 视频 / 编辑模式切换
- 模型、比例、分辨率、数量等紧凑参数
- 展开后的详细参数
- 生成按钮
- 排队、生成、成功、失败和重试状态
- 当前请求的结构化参考素材
- 按 `request_id` 归组的任务与结果状态

参数默认收起，生成结果完成后自动添加到画布。生成失败应在对应节点上提供重试，不离开当前画布。

## 智能体会话与直连请求

原有 `AgentCopilot` 不作为自由创作首屏的固定右侧面板。它保留为可选辅助面板，入口放在顶部工具栏或底部输入框的辅助模式中。

建议区分两类交互：

1. **生成输入**：直接创建图片、视频或编辑任务，是默认入口。
2. **智能体辅助**：优化提示词、解释参数、整理画布、批量处理节点，是可选入口。

底部输入框虽然采用对话式外观，但仍是直连生成器：每次提交创建一个 `request_id`，数量大于 1 的并列结果共享该标识。它不写入 Agent 消息，也不把一次提交伪装成会话。画布按 `parent_creation_id`、结构化引用和 `request_id` 展示来源与批次关系。

真正的多轮智能体会话继续使用现有 `AgentCopilot` 会话存储和事件日志；收起入口位于画布右上工具组下方并保留间距。重新进入项目时，Agent 会话由原会话系统恢复，画布位置和缩放由独立画布状态恢复，两者不共享或复制真相源。

## 首页过渡

首页 `/app` 发送自由创作内容后，继续创建项目并进入 `/app/projects/:projectName`，但需要把提交上下文交接给画布：

```text
首页提示词
  → 创建 content_mode=free 项目
  → 进入自由无限画布
  → 显示生成中节点
  → 结果节点出现在画布
```

详情页不能先展示空的标准概览，再要求用户重新寻找输入框。首页传递的上下文应包括输出类型、模型、比例、分辨率、数量、尺寸或视频时长，以及任务 ID 和当前状态。

普通项目仍走现有创建向导、项目列表和标准详情流程；首页自由创作的交接逻辑不能改变普通项目的创建参数或跳转行为。

## 状态与持久化

自由画布的节点由自由创作记录和任务状态派生。节点位置、画布缩放和平移、隐藏集合等 UI 状态单独保存为项目范围的自由画布元数据，并通过修订号处理并发更新；不得写入标准脚本字段或伪装成剧集产物。

自由产物继续使用现有 `creations/` 和 `artifact_manifest`；画布不创建第二套媒体清单。删除、版本、归档、下载和成本归属继续遵循自由创作领域契约。

上传入口以 `+` 号放在底部创作框内。上传完成后素材自动成为画布节点并加入当前请求的引用列表；点击任意已完成卡片也可生成固定到该版本的结构化引用。前端不要求用户输入或复制项目文件路径。

视频时长控件展示 0 到当前型号最短档位的灰色禁用区，并只吸附到能力接口声明的离散档位。默认值取第一档，最大值取最后一档；30 秒只是部分型号可能声明的上限，不是自由创作的全局规则。

自由项目顶部栏不显示固定工作流阶段和剪映导出。专属“导出作品”按三种范围工作：框选的已完成作品、同一个 `request_id` 的结果、项目内全部已完成作品。导出只收录 `artifact_manifest` 中有正式声明的自由产物，不默认混入上传素材、失败任务或画布布局状态。

## 品牌图标

将仓库根目录的 `logo.jpg` 作为当前品牌图标来源，替换登录页、项目首页、工作区品牌区域、浏览器 favicon、PWA manifest 以及文档站 Logo 中引用的旧图标。替换时需检查小尺寸清晰度、裁切比例、深色背景对比度和 maskable 安全区。

图标替换属于品牌资源变更，不应改变任何项目模式、路由或生成任务行为。

## 实施阶段

### 阶段一：模式边界

- 在工作区入口选择标准工作区或自由工作区。
- 自由项目不加载标准侧边栏和剧集区域。
- 自由项目访问 `/source`、`/characters`、`/scenes`、`/props` 时回到自由画布。
- 标准项目回归测试保持通过。

### 阶段二：画布壳层

- 实现缩放、平移、适应画布和节点选择。
- 实现提示词、媒体结果和任务状态节点。
- 实现来源连线和基础节点操作。
- 画布相关依赖按自由路由懒加载。

### 阶段三：创作框与会话

- 实现底部生成输入框。
- 接入图片、视频和编辑任务。
- 以 `request_id` 归组直连任务；真实多轮会话继续复用 AgentCopilot。
- 将 Agent 辅助改为可选面板。

### 阶段四：首页交接

- 首页提交后进入自由画布。
- 交接首条提示词、参数和任务状态。
- 显示首个生成节点及其失败重试。
- 验证浏览器返回、刷新和项目列表回到行为。

### 阶段五：品牌与视觉

- 统一使用 `logo.jpg`。
- 画布使用低干扰背景和克制的渐变、模糊、发光。
- 完成桌面端、窄屏和键盘操作检查。

## 回归验收

### 自由创作

- 进入项目后直接看到无限画布和底部创作框。
- 不显示标准项目侧边栏、剧集、脚本和资产模块。
- 生成结果、失败任务和编辑分支均能在画布中追踪。
- 刷新后任务节点、引用关系和画布位置可恢复。
- 旧自由项目路径不会出现空白页或死按钮。

### 其他模式

- `drama`、`narration`、`ad` 的侧边栏、脚本、剧集、时间线和 Agent 面板不变。
- 标准项目的创建、跳转、任务和成本行为不变。
- 标准项目不会加载无限画布专属依赖。
- 自由画布异常不会回退到标准 `OverviewCanvas` 或 `TimelineCanvas`。
- 现有标准模式测试和自由模式测试均通过。

## 风险与控制

| 风险 | 控制措施 |
| --- | --- |
| 纯 Canvas 导致交互和无障碍成本过高 | 使用 Canvas/SVG 空间层与 DOM 媒体节点混合渲染 |
| 自由模式逻辑污染标准工作区 | 在路由/工作区入口分流，禁止公共组件散落模式判断 |
| 画布状态与产物清单出现两套真相源 | 由会话事件、任务和 artifact manifest 派生节点 |
| 首页进入画布时出现空白或重复输入 | 使用首条消息和任务 ID 做显式交接 |
| 画布节点数量增长导致性能下降 | 节点虚拟化、按视口渲染和路由级懒加载 |
