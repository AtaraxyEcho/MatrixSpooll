# 自由创作无限画布采用混合渲染与增量协作

## 背景

自由创作画布同时承载上传素材、生成产物、字幕节点、引用关系和分组。全量 DOM/SVG 渲染、整份画布 JSON 保存和逐文件读取元数据，会随作品数量增长而放大布局、媒体解码、网络与并发写入成本。

## 决定

- 画布使用混合渲染。详情层只挂载视口及预取区内最多 160 个交互式 DOM 卡片；概览层和紧凑层由 Canvas 2D 绘制缩略图、状态、关系线与分组框。
- 使用 RBush 空间索引处理视口裁剪、低缩放命中测试和框选。自动化几何测试覆盖 10,000 个节点；产品可用性目标为单项目约 5,000 个素材或产物，而不是承诺 10,000 个同时播放的媒体元素。
- LOD 使用带滞回的阈值切换，避免临界缩放反复闪烁。选中态在三层间保持；详情层退出前记录视频播放时间和播放态，返回详情层后恢复。
- 摄像机独立于共享画布保存，每位用户拥有自己的视口。平移在操作结束和滚轮移动时钳制，至少保留半个视口范围内的内容；工具栏提供适配全部与适配所选，minimap 提供直接导航。
- 节点拖拽使用 Smart Guides：实时比较拖拽节点组与其他元素的边缘线、中心线，进入 8px 屏幕阈值后自动吸附，并沿目标对齐轴绘制贯穿画布的虚线；松手立即清除参考线。工具栏可关闭吸附，按住 `Alt` 可临时跳过当前拖拽的吸附，不使用背景网格吸附。
- 共享状态使用节点级 PATCH。每个节点、分组和关系显示开关拥有独立修订号；不同目标的过期 PATCH 可合并，同一目标冲突时以服务端状态为准并重放不冲突的本地变化。`patch_id` 提供幂等，最近 200 个 ID 随画布状态保存。
- 项目事件 SSE 传递已应用的画布 PATCH，客户端按序增量合并。新客户端仍以 `GET free-creation-canvas` 取得权威快照。旧整包更新接口仅作协议兼容，新画布不调用，也不提供旧渲染器回退开关。
- 撤销/重做使用 `Ctrl/Cmd+Z` 与 `Ctrl/Cmd+Y`（同时支持 `Cmd/Ctrl+Shift+Z`）。历史最多 50 个内容命令且受 16MB 序列化预算约束；摄像机移动不进入内容历史。删除命令记录外部恢复/再次删除动作。
- 元数据列表通过可重建的 `free_creation/index.json` 读取，产物或上传记录变更时使索引失效。索引不是单一真相源，损坏或缺失时从原始 JSON 重建。
- 生成视频沿用生成阶段产出的封面；上传视频在上传后后台提取首帧。详情卡片首次请求视频时立即返回原文件并最多并发 2 路生成 480p 无音轨代理，后续请求使用代理。代理缓存默认每项目 4GB，可由 `MATRIXSPOOLL_PREVIEW_CACHE_MB` 在 256MB 至 64GB 间调整，超限清理最久未访问文件；原始媒体不受清理影响。

## 复制语义

画布节点 ID 对应真实上传或生成产物，目前不支持在画布内复制/粘贴出第二个同 ID 节点，也不复制生成产物。这样可避免伪造或模糊 `parent_creation_id`、`reference_claims` 与版本来源。用户把已有卡片引用到创作框属于引用操作，不是节点复制。

## 验证边界

- 几何与 LOD：10,000 节点空间查询、摄像机钳制、适配视图、Smart Guides 边缘/中心线吸附、双向同轴连线端点。
- 历史：50 步上限、16MB 预算、撤销后重做、新操作清空重做栈。
- 并发：不同节点的过期写合并、同节点写冲突、PATCH 幂等、分组与显隐原子更新、前端冲突重放。
- 交互：单选、框选、分组移动、批量删除、隐藏/恢复、低 LOD 右键与双击、文件拖入防重复导入。

## 后果

正常视口内的 DOM 与视频解码数量由视口和 LOD 上限决定，而不是由项目总量决定。5,000 个节点仍会增加索引、minimap、首次元数据加载和磁盘代理缓存成本，但不会创建 5,000 个 `<video>` 或卡片 DOM。多用户同时编辑不同节点可直接合并；同时编辑同一节点会显式收敛到服务端版本。
