# Agent 模式 {#agent-mode}

Agent 模式把自然语言意图转换为项目操作和生成任务。它不会与图片或视频生成器并行常驻；用户在输入框的同一个模式控件中选择 Agent、生成图片或生成视频。

## 自动与自定义 {#automatic-and-custom}

- **自动**：Agent 根据输入和项目上下文判断输出图片还是视频，并选择可用模型、比例和分辨率。
- **自定义**：用户指定生成偏好、模型、比例和分辨率，Agent 在这些约束内规划。

自动模式只负责推荐与编排，最终请求仍经过模型能力校验和任务队列。切换到自定义后，不支持的参数不会被视为模型能力。

## 会话与项目 {#sessions-and-projects}

首页发送 Agent 请求时会先创建自由创作项目，再为该项目建立会话。项目详情页的 Agent 对话显示在左侧会话区域，底部创作输入框保持原位。任务完成后，图片或视频结果进入当前项目画布。

会话与创建它的项目绑定。删除项目、无权访问项目或配置切换导致会话不可恢复时，应新建会话；错误卡片会展示可操作的原因，而不是只显示供应商原始异常。

## 供应商要求 {#provider-requirements}

当前 Agent Runtime 基于 Claude Agent SDK，智能体供应商必须提供兼容的 Anthropic Messages 协议和可用模型。普通文本模型即使提供 OpenAI Chat Completions，也不能自动当作 Agent 供应商。配置页会探测协议兼容性并在测试失败时说明路由、模型访问或凭证问题。

图片、视频和 TTS 供应商是系统级配置，由管理员统一维护；Agent 只调用当前已启用且能力匹配的生成端点。
