# 自由创作与无限画布 {#free-creation-canvas}

自由创作适合直接从提示词和参考素材生成图片或视频，不要求先准备源文件、分集、脚本或分镜。它仍然属于项目，因此参数、素材、生成记录和画布位置可以持续保存。

## 从首页开始 {#start-from-home}

首页输入框默认创建自由创作项目，并截取部分输入作为项目名称。选择图片、视频或 Agent 模式后，模型、比例、分辨率、数量和时长控件会根据当前模型声明的能力变化；不支持的组合应在入队前提示，而不是静默替换。

图片模式会根据比例和分辨率联动宽高，视频模式默认把提示词直接交给视频模型。只有选择 Agent 模式时，文本模型才负责理解意图、选择工具并编排任务。

## 参考素材 {#references}

- **全能参考**：上传素材后由系统根据文件类型映射为图片、视频、音频或提示上下文，无需逐个选择内部参数名。
- **首尾帧**：显示独立的首帧、尾帧卡片，并可交换两者。该入口只在模型声明支持时可用。
- **画布引用**：`Ctrl + 单击`素材把它加入当前创作请求；普通单击用于选择，双击用于预览，避免引用与预览冲突。

模型能力是最终约束。界面显示某种引用方式不代表所有模型都支持；切换模型后应重新检查引用数量、类型、比例、分辨率和时长。

## 画布操作 {#canvas-operations}

- 拖拽空白区域平移，滚轮或缩放控件调整视图；缩放下限为 40%，平移不受素材包围框限制。
- 拖动素材接近其他元素的边缘或中心时显示智能参考线，并在阈值内吸附。
- 单选或框选后可以组合、隐藏或删除；批量右键菜单只显示适用于当前选择的操作。
- `Ctrl + Z` 撤销，`Ctrl + Y` 重做。删除、隐藏、移动和批量操作应进入同一历史记录。
- 图片和视频双击打开自适应预览；视频卡片显示封面并保留播放入口。
- 视频合并、字幕和部分代理媒体处理依赖 FFmpeg。缺失或片段不兼容时会明确报错，不会损坏原视频。

### 字幕与配音派生 {#subtitle-and-audio-derivations}

字幕轨在画布中是可操作的独立卡片：单击选中、拖拽移动、双击编辑，右键或卡片更多菜单可以编辑、隐藏、生成带字幕视频或删除字幕轨，也可以与视频一起组合。只有字幕轨时显示“源视频 → 字幕”；生成带字幕视频后改为“源视频 → 带字幕视频”和“字幕 → 带字幕视频”。新视频优先放在字幕卡片右侧并进行碰撞检测。

配音合成会保留视频与音频两个来源，生成结果同时关联这两个素材。它不会修改原视频或原音频；合成产物作为新视频出现在来源素材右侧。字幕烧录和配音合成都依赖 FFmpeg。

## 项目参数 {#project-parameters}

比例、分辨率、模型、生成数量和时长按项目保存。离开再进入同一项目时恢复该项目最近一次有效选择；项目创建时设置的比例作为首次进入的默认值。
