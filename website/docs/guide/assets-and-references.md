# 资产与参考素材 {#assets-and-references}

MatrixSpooll 区分全局资产、项目资产和自由画布参考素材，避免把“可跨项目复用的定义”与“一次生成请求的输入”混为一谈。

## 三种层级 {#three-levels}

1. **全局资产库**：保存可复用的角色、场景和道具记录，由权限允许的用户维护。
2. **项目资产**：项目 `project.json` 中的角色、场景、道具和产品定义，是该项目工作流的真相源。
3. **画布参考素材**：上传到自由创作项目的图片、视频、音频和文本，仅在绑定到请求时影响生成。

剧本和分集只引用资产名称，不复制完整定义；项目摘要中的产物计数、状态和时长由已有产物实时计算。

## 导入与预览 {#import-and-preview}

画布可导入常见图片、音频、视频以及剧本或剧情说明文本。文本类素材用于提示上下文，不会自动当作需要发布的媒体。双击卡片打开预览；`Ctrl + 单击`把素材加入创作框，普通单击只负责选择。

## 能力联动 {#capability-linkage}

绑定参考素材后，输入框根据当前模型能力显示全能参考、首尾帧等入口，并检查允许的类型和数量。全能参考会按文件类型在业务层映射，不暴露 `reference_image`、`reference_video`、`reference_audio` 或 `prompt_context` 等内部参数。

参考关系会记录到生成请求和画布索引，便于查看某个结果使用了哪些上游素材。组合只是画布组织，不会伪造新的生成产物或修改原始派生关系。
