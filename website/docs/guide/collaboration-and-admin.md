# 用户、协作与管理 {#collaboration-and-admin}

MatrixSpooll 采用简化的多用户模型：系统管理员管理账号和运行状态，项目权限由所有者、编辑者和查看者三种角色组成。

## 系统角色 {#system-roles}

- **超级管理员**：由部署环境初始化，不可在管理端降级、禁用或删除。
- **管理员**：管理用户、在线会话、系统日志和后台任务，并维护系统级供应商配置。
- **成员**：使用被授权的项目和资产，不显示无权限的系统设置入口。

管理端位于 `/app/admin/manager`，独立登录入口为 `/admin/login`。

## 项目角色 {#project-roles}

- **所有者**：管理项目设置、成员和所有权转移。
- **编辑者**：编辑项目内容和常用项目设置，但不能转移所有权。
- **查看者**：只读访问；项目设置入口会隐藏，路由层也会再次拒绝越权访问。

项目名称不要求跨用户唯一。前端可以继续显示名称，后端始终使用稳定的项目 ID 处理授权、成员关系和文件路径。

## 登录会话 {#login-sessions}

管理端会话页只显示当前在线会话。相同账号从同一浏览器标识或同一来源 IP 再次登录时，新会话会替换旧会话；旧页面通过事件流收到“账号已在其他设备登录”的提示并退出。管理员可以在会话页主动下线指定在线会话。

登录日志与在线会话分开保存：会话表表示当前访问状态，登录日志用于追踪成功、密码错误、空输入和其他认证事件。
