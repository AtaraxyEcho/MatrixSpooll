# 项目备份与媒体工具 {#project-transfer-and-media}

## 项目 ZIP {#project-zip}

项目列表可以导出完整项目 ZIP，并从“导入项目 ZIP”恢复。标准工作流和自由创作项目都支持该流程；导入器会验证归档结构、JSON 大小、条目数量、单文件大小、总展开大小和压缩比，拒绝普通 ZIP、路径穿越和压缩炸弹。

导入成功后会创建新的项目身份，避免覆盖已有项目或继承旧成员关系。归档缺少兼容字段时，迁移层会补齐可安全推断的默认值；无法推断的必填字段会返回明确错误。

ZIP 是项目级备份，不包含数据库中的用户、成员、系统供应商密钥、登录日志或全局配置。完整灾备仍需同时备份 PostgreSQL 和 `deploy/production/projects/`。

## 媒体工具 {#media-tools}

自由画布支持视频合并、字幕生成、代理视频和缩略图。它们依赖 FFmpeg/FFprobe，并在后台执行，避免阻塞 Web 请求。生产镜像已内置并通过健康检查验证；本地开发需要把可执行文件加入 `PATH`。

合并不会重新解释提示词或调用生成模型，而是按选择顺序处理本地片段。编码、尺寸、音轨或容器差异无法安全归一化时，任务会失败并保留原文件。大型视频会消耗额外 CPU、磁盘和临时空间，建议在低峰期操作并监控磁盘余量。
